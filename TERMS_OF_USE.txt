count installations by country and by day. That service works out the country
from the IP address the notice comes from, records that country and the day it
arrives, and does not keep the IP address. Without an internet connection, the
notice is sent at a later start. Updates do not send it.

New versions are published on the official site. When it starts, the
application checks that site to see whether a more recent version exists. This
check includes no business data of the user; the service that receives it
(GitHub) records the IP address it comes from, as with any visit to a website.

If a new version exists, the application says so and only downloads and
installs it when the user asks. Before installing it, it verifies that it is
signed by the owner and, if the signature is not valid, it does not install
it. Without an internet connection, the check is not made and the application
works normally.
